# 📄 ResuCoach AI — AI Resume & Mock Interview Coach

**ResuCoach AI** is a full-stack career preparation web application designed for students and job seekers. It analyzes resumes against target job roles, computes ATS compatibility scores, detects missing technical skills, generates high-impact power bullet rewrites, and conducts interactive AI voice mock interviews.

---

## 🌟 Core Features

1. **📄 Resume File Upload & Parsing**: Drag & drop PDF, DOCX, or paste resume text directly.
2. **🎯 Target Job Role Selection**: Specialized algorithms for *Full Stack Developer*, *Frontend Developer*, *Backend Engineer*, and *Data Scientist*.
3. **📊 0–100 ATS Resume Readiness Score**: Detailed metrics for Keyword Match %, Impact Action Verbs, and Formatting.
4. **✨ AI Power Bullet Rewrites**: Transforms weak resume descriptions into metric-driven power bullets (e.g. *"Engineered 15+ React components, improving load speed by 25%"*).
5. **🎙️ AI Voice Mock Interview Coach**: Role-specific technical, architecture, and behavioral questions with live speech-to-text recording and instant AI evaluation.
6. **📈 Career Progress Dashboard**: Chart.js progression tracking of ATS resume scores over time.
